# HP-21 (Woodstock): архитектура и отличия от HP-35 (Classic)

Справка для работы над эмулятором `HPVMWoodstock.h`. Собрана по результатам исследования (deep-research) и проверена по первоисточникам Nonpareil (`proc_woodstock.c`, `21.asm`, `21.ncd.tmpl`).

Всё побитовое поведение взято из Nonpareil Эрика Смита. Это реконструкция по дизассемблированию, а не документация HP. Общую архитектуру независимо подтверждает HP Journal за ноябрь 1975 года.

## 1. Аппаратура HP-21

| Микросхема | Номер HP | Что внутри |
|---|---|---|
| **ACT** (Arithmetic, Control & Timing) | 1820-1523 | АЛУ, все регистры, 16 статус-битов, P, PC, 2 регистра возврата, сканер клавиатуры, входы флагов F1/F2 |
| **ROM + анодный драйвер** | 1818-0129 | ROM 1024×10 бит и 7-сегментный знакогенератор |
| **Катодный драйвер** | 1820-1382 | 12 разрядов индикатора |

- Отдельной RAM-микросхемы нет, она есть только у HP-22/25. Единственный регистр STO/RCL — это **M1** внутри ACT.
- Тактирование: LC-генератор **185 кГц**. Слово — 14 BCD-разрядов, 56 бит, это около 3300 инструкций в секунду. Частота известна только из Nonpareil.
- Переключатель DEG/RAD подключён к флагу **F2**, линия батареи — к флагу **F1**.

## 2. Программная модель ACT

- **Регистры по 14 BCD-разрядов:** A, B, C (это X), Y, Z, T, M1, M2.
- **Короткие регистры:**
  - F — 4 бита. В HP-21 хранит формат дисплея: при включении становится 2 (FIX 2), `clear regs` его не очищает.
  - P — 0..13; инкремент и декремент заворачивают 13↔0.
- **Флаги:** carry/prev_carry и режим decimal/binary (основание 10 или 16).
- **16 статус-битов** (по заголовку `21.asm`):

| Бит | Назначение в HP-21 |
|---|---|
| s1 | рабочий; судя по коду, флаг SCI/FIX (вывод, а не утверждение источника) |
| s2 | подъём стека разрешён |
| **s3** | RAD. Каждый цикл выполняется `s3 \|= F2`. ROM сам делает `0 -> s 3`, а аппаратура тут же выставляет бит обратно |
| **s5** | питание. Каждый цикл `s5 \|= !F1`, при нормальной батарее s5 = 1 |
| s9 | была введена десятичная точка |
| s13 | нажат shift |
| s14 | идёт ввод порядка |
| **s15** | нажата клавиша. Каждый цикл `s15 \|= key_flag` |
| s0, s11, s12 | не используются |

- `clear status` очищает все биты, кроме **s1, s2, s5, s15**.
- `clear regs` обнуляет A, B, C, Y, Z, T. **M1, M2, F и P остаются.**

## 3. Кодировка инструкций

Слово 10-битное, тип задают младшие 2 бита. В коде проекта используется `op_code = rom_h = word >> 2`.

| Тип | Формат | Действие |
|---|---|---|
| 01 | `aaaaaaaa01` | jsb в пределах текущей 256-словной страницы |
| 10 | `ooooowww10` | арифметика: `op = rom_h >> 3`, `field = rom_h & 7` |
| 11 | `aaaaaaaa11` | goto в пределах страницы, только если `!prev_carry` |
| 00 | — | misc |

**Поля** (номер → разряды): 0 p (p..p), 1 wp (0..p), 2 xs (2), 3 x (0..2), 4 s (13), 5 m (3..12), 6 w (0..13), 7 ms (3..13).

**Арифметика** (номер операции = `rom_h >> 3`):

| | | | |
|---|---|---|---|
| 00 `0→a` | 08 `0→c` | 10 `a−b→a` | 18 `if a>=c` |
| 01 `0→b` | 09 `a+b→a` | 11 `a−c→c` | 19 `if a>=b` |
| 02 `a↔b` | 0A `a+c→a` | 12 `a−1→a` | 1A `if a#0` |
| 03 `a→b` | 0B `c+c→c` | 13 `c−1→c` | 1B `if c#0` |
| 04 `a↔c` | 0C `a+c→c` | 14 `0−c→c` | 1C `a−c→a` |
| 05 `c→a` | 0D `a+1→a` | 15 `0−c−1→c` | 1D `shr a` |
| 06 `b→c` | 0E `shl a` | 16 `if b=0` | 1E `shr b` |
| 07 `b↔c` | 0F `c+1→c` | 17 `if c=0` | 1F `shr c` |

Все тесты (16–1B) переводят ACT в состояние then-goto. Условие считается выполненным, если carry = 0.

**Misc-инструкции с параметром.** Старшая тетрада `rom_h` — это n (0..15), младшая тетрада задаёт операцию:

| Младшая тетрада | Операция |
|---|---|
| 1 | `1 -> s n` |
| 3 | `0 -> s n` |
| 5 | `if 1 = s n`, carry = !s |
| 6 | load constant n |
| 7 | `if 0 = s n`, carry = s |
| 8 | select rom n |
| 9 | `if p = n` (через `p_test_map`) |
| A | c→register n (RAM, в HP-21 не используется) |
| B | `if p # n` |
| D | delayed rom n |
| E | register→c (RAM, в HP-21 не используется) |
| F | `p <- n` (через `p_set_map`) |

- `p_set_map = {14,4,7,8,11,2,10,12,1,3,13,6,0,9,5,14}`
- `p_test_map = {4,8,12,2,9,1,6,3,1,13,5,0,11,10,7,4}`

**Misc-инструкции с фиксированным кодом** (значение `rom_h`):

| Код | Инструкция | Код | Инструкция |
|---|---|---|---|
| 0x00 | nop | 0x04 | keys → rom address |
| 0x02 | clear regs | 0x14 | keys → a *(не используется)* |
| 0x12 | clear status | 0x24 | a → rom address *(не используется)* |
| 0x22 | display toggle | 0x34 | display reset twf *(не используется)* |
| 0x32 | display off | 0x44 | binary |
| 0x42 | m1 ↔ c | 0x54 | circulate a left *(не используется)* |
| 0x52 | m1 → c | 0x64 | p − 1 → p |
| 0x62 | m2 ↔ c | 0x74 | p + 1 → p |
| 0x72 | m2 → c | 0x84 | return |
| 0x82 | stack → a (a=y, y=z, z=t) | 0xC2 | decimal |
| 0x92 | down rotate | 0xE2 | f → a[0] |
| 0xA2 | y → a | 0xF2 | f ↔ a[0] |
| 0xB2 | c → stack (t=z, z=y, y=c) | 0xFC | «hi i'm woodstock» = nop |

## 4. Поток управления

- PC 12-битный. В начале каждого цикла: `prev_carry = carry; carry = 0; pc++`.
- **then-goto:** слово, следующее за тестом, целиком является 10-битным адресом. Переход `pc = (pc & ~0x3FF) | word` выполняется, если `!prev_carry`.
- **jsb/goto** заменяют только младшие 8 бит PC.
- **Стек возвратов:** 2 уровня по 12 бит, кольцевой. При переполнении молча заворачивается. Полный 12-битный адрес восстанавливает только return.
- **select rom n:** сразу выполняется `pc = (n<<8) | (pc & 0xFF)`.
- **delayed rom n:** то же самое, но применяется после следующей инструкции. В `21.asm` она стоит перед `go to`.

## 5. Клавиатура и цикл ожидания

Hex-коды клавиш (в скобках — восьмеричные):

| Ряд | Клавиши и коды |
|---|---|
| 1 | 1/x B4 (0264), SIN B3, COS B2, TAN B1, **f** B0 |
| 2 | x↔y 44 (0104), R↓ 43, eˣ 42, STO 41, RCL 40 |
| 3 | ENTER D4 (0324), CHS D2, EEX D1, CLx D0 |
| 4 | − 64, 7 63, 8 62, 9 61 |
| 5 | + A4, 4 A3, 5 A2, 6 A1 |
| 6 | × 74, 1 73, 2 72, 3 71 |
| 7 | ÷ 94, 0 93, . 92, DSP 91 |

Таблица совпадает с `key_tokens` в `HP21Model.h`. `keys -> rom address` выполняет `pc = (pc & ~0xFF) + keycode`, поэтому обработчики клавиш лежат на странице 1 (адреса 0400–0777₈).

Цикл ожидания клавиши в ROM (адреса проверены по ROM в `HP21Model.h`):

```
0363 getkey: 0 -> s 13
0364         c -> a[s]
0365         display toggle
0366 wait:   0 -> s 15
0367         p <- 7
0370 wait1:  p - 1 -> p
0371         if p # 0 / 0372 then go to wait1
0373         if 1 = s 15 / 0374 then go to wait     ; антидребезг: ждём отпускания
0375         hi i'm woodstock
0376 wait2:  if 0 = s 15 / 0377 then go to wait2   ; <- IDLE = 0x0FE
0400         display off
0401         p <- 0
0402         0 -> a[p]
0403         keys -> rom address
```

## 6. Дисплей

- Сканируются разряды A/B с 13 по 2, это 12 позиций.
- **Если `B[i] & 2`:** при `A[i] >= 2 && (A[i] & 7) != 7` выводится «−», иначе пусто.
- **Иначе:** выводится символ знакогенератора для `A[i]`.
- **Если `B[i] & 1`:** добавляется точка.
- **Знакогенератор:** 0–9, A=r, B=H, C=o, D=P, E=E, F=пробел. Сообщение «Error» ROM собирает через load constant 14, 10, 10, 12, 10.
- Дисплей включён только в getkey: `display toggle` по адресу 0365, `display off` по адресу 0400. Во время вычислений он погашен.
- Режим `display_14_digit` (reset twf) в HP-21 не используется.

## 7. Особенности ROM HP-21

- 1024 слова: 4 страницы по 256. Межстраничные переходы идут через `select rom 00..03` (25 раз) и один `delayed rom`.
- При включении выполнение начинается с адреса 0000: `a+1→a[w]` дважды и `f↔a`, после чего F = 2.
- STO и RCL работают с **M1**: `ksto: m1 exchange c`, `krcl2: m1 -> c`. M2 используется как рабочий регистр.
- Инструкции, которых в ROM нет: keys→a, a→rom address, circulate a left, reset twf, все RAM-операции, bank switch, selftest.

## 8. Отличия HP-21 от HP-35

| Аспект | HP-35 (Classic) | HP-21 (Woodstock) |
|---|---|---|
| Микросхемы | C&T, A&R, 3 ROM, драйверы | ACT, ROM+анодный драйвер, катодный драйвер |
| ROM / адрес | 768 слов (3×256): 8-битный pc + номер ROM | 1024 слова: 12-битный PC, 4 страницы |
| Такт | 200 кГц (в `HPVMClassic.h`) | 185 кГц |
| Регистры | A–F, M | A, B, C, Y, Z, T, M1, M2 + F (4 бита) |
| Статус-биты | 12; `clear status` очищает все | 16; сохраняются s1, s2, s5, s15 |
| Флаг клавиши | s0 | s15 |
| Стек возвратов | 1×8 бит | 2×12 бит, кольцевой |
| Тест и переход | тест + обычный 8-битный goto | тест + then-goto с 10-битным адресом |
| Тесты s и p | `if s=0`, `if p#n` | `if s=0/1`, `if p=/#` |
| Кодирование P | n прямо, wrap через `&0x0F` | через p_set/p_test, wrap 0..13 |
| Порядок полей | P, M, X, W, WP, MS, XS, S | P, WP, XS, X, S, M, W, MS |
| Номера арифм. операций | например, `if b=0` = 0x00 | другая нумерация, `if b=0` = 0x16 |
| Hex-режим | нет | binary/decimal |
| keys→rom | pc = key | pc = страница \| key |
| clear regs | очищает A–F и M | очищает A–T; M1, M2, F сохраняются |
| Дисплей | 15 позиций; B=9 пробел, B=2 точка | 12 позиций; маски B&2 и B&1, символы r/H/o/P/E |
| Idle | BP 0x00C5 и s8 | 0x0FE и s15 = 0 |
| DEG/RAD | только градусы | переключатель F2 → s3 |
| Клавиши | 35, префикс ARC | 30, shift f, DSP (FIX/SCI) |

## 9. Сверка с `_HPVMWoodstockV2.h`

Все инструкции, которые встречаются в ROM HP-21, реализованы в черновике с той же семантикой, что в Nonpareil. Это касается порядка полей, всех 32 арифметических операций и поведения carry, misc-кодов, then-goto, двухуровневого стека, select/delayed rom, таблиц p_set/p_test, правил для s3/s5/s15, адреса wait2 = 0x0FE и отрисовки дисплея.

Что в черновике отличается:

1. **Частота.** `HPVM_CLOCK_RATE 200`, а нужно 185, как в Nonpareil и в заглушке `HPVMWoodstock.h`.
2. **Структура не по CLAUDE.md.** ROM подключается через `HP21ROM.h` внутри VM, а не из `HP21Model.h`. Перечисление клавиш и `shifted_keys` лежат в заголовке CPU. API отличается: есть `Radians()` и `Error()`, нет `OpAndWait`.
3. **Дисплей.** Отрисовка идёт на toggle/off и при входе в idle, а не непрерывным сканированием. Для HP-21 это равнозначно, потому что дисплей включается только в getkey.
4. **Не проверено.** В черновике `alu()` маскирует результат через `& 0x0F`. Как Nonpareil (`digit_ops.c`) поступает с hex-цифрами в десятичном режиме, не проверялось.

## 10. Что осталось непроверенным

- Частота 185 кГц и номера микросхем известны только из Nonpareil.
- По другим эмуляторам (jrpn, panamatik) проверенных данных нет.
- ROM в `HP21Model.h` сверен выборочно: адреса 0000–0007 и 0373–0404. Полного дизассемблирования не делалось.
- Nonpareil распространяется под GPL. Использовать его стоит как спецификацию, не копируя код.
